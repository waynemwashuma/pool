# Pool

A small browser-based pool game built with plain HTML, CSS and JavaScript. The project uses the Canvas API for rendering and physics, includes a simple landing page.

## Run Locally

If you want to serve this locally, run one of these from the project folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Controls

- `Left` / `Right` arrows: aim the cue
- `Up` / `Down` arrows: increase or decrease shot power
- `Space`: shoot

On mobile, keep the device in portrait orientation for the best experience
